# Question policy

## When to ask

Ask only when the answer materially affects credibility, positioning,
portfolio audience, project selection, content depth, personal
contribution, confidentiality, contact action, primary role, portfolio
emphasis, or high-level presentation.

Do not ask low-value factual gaps that can be safely omitted. Do not
force a question quota.

## Selection rubric

Score each candidate question on:

- Downstream impact (0-4)
- Credibility risk (0-4)
- Conflict resolution value (0-4)
- Information gain (0-4)
- Target-role relevance (0-3)
- Already-answered penalty (0-5)
- User-effort penalty (0-3)
- Sensitivity penalty (0-4)
- Can safely omit instead (yes/no)
- Can Auto decide (yes/no)

Keep blocking credibility conflicts first, then primary role and goal
questions, then project contribution and confidentiality questions.
Combine tightly related questions. Remove questions already answered by
high-confidence source evidence.

## Counts

- Complete profile: 0-3 questions.
- Ordinary incomplete profile: 5-8 questions.
- Extremely sparse profile: focused onboarding set, usually 5-8.
- Conflict-heavy profile: most consequential conflicts, maximum 8.

## Question-writing quality

Every question should:

- Ask one clear decision or one tightly coupled set.
- Explain why it matters when helpful (why_it_matters).
- Use the requested output language.
- Avoid jargon and accusatory wording.
- Avoid requiring the user to understand internal schemas.
- Offer "Other" where appropriate.
- Offer skip only when safe.
- Offer Auto only for presentation decisions.
- Have stable option IDs.
- Avoid overlapping another question.
- Never ask the user to rewrite their resume.

Bad: "Tell us more about yourself."
Good: "Which role should this portfolio optimize for first? — Backend
Engineer / Platform Engineer / Full-stack Engineer / Another role."

Bad: "What metrics did you achieve?"
Good (only when a metric would materially help): "Do you have a verified
result for the queue-reliability work that can be published? — Yes, I
will provide it / No verified metric / The result is confidential / Skip
this detail."
