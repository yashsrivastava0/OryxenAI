# Anti-example: weak question vs scoped question

BAD QUESTION:
"What are your greatest strengths?"

REASON:
It is vague, invites generic self-promotion, and does not change
positioning or project selection.

GOOD QUESTION:
"Which capability should lead the portfolio: API design, data systems,
production reliability, or another area?"

REASON:
The second question changes downstream positioning and is easier to
answer concretely.
