# Anti-example: unsupported metric

BAD:
"Improved system performance by 40%."

REASON:
No metric exists in the source. A numeric claim without evidence is a
fabrication.

GOOD:
"Worked on reliability and performance improvements."
(Only when the source supports that qualitative statement.)

BEST WHEN CONTRIBUTION IS UNCLEAR:
Omit the outcome and ask who owned the performance work instead of
guessing.
