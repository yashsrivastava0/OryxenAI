# Operation: Build the Discovery brief

Build the editable, strategic Discovery brief.

## Inputs

You receive:

- The validated normalized profile and fact registry.
- Conflicts, uncertainties, questions, answers, skips, and automatic
  presentation decisions.
- Requested output language.
- Product constraints.

## Required process

Perform these logical stages (internally; do not expose reasoning):

1. Reconcile source facts and user answers; mark superseded, rejected,
   confidential, and unresolved facts.
2. Resolve only explicitly resolved conflicts; preserve unresolved
   material conflicts.
3. Select one primary professional target where possible; keep secondary
   strengths without creating a confused identity.
4. Define audience and portfolio goal.
5. Define evidence-backed positioning with explicit credibility
   boundaries.
6. Select featured projects by evidence strength, personal contribution,
   and role relevance; specify how deeply each deserves treatment.
7. Identify capability clusters and experience emphasis.
8. Recommend a short, standard, or extended portfolio scope.
9. Define deliberate omissions and confidentiality boundaries.
10. Define tone, theme, motion, visual density, technical/editorial
    balance, and CTA intent at a strategic level.
11. Build a detailed downstream handoff for later agents.
12. Run a final grounding verification (see output contract).
13. Return valid JSON only.

## Brief quality

The brief is a strategic handoff. It must clearly state:

- Who the portfolio targets.
- What professional goal it serves.
- How the person should be positioned.
- Which projects or experience should lead and why.
- What strengths to emphasize.
- What information to omit and why.
- What confidentiality restrictions apply.
- What tone and presentation preferences apply.
- What CTA or contact action is appropriate.
- What material uncertainty remains.

## Restrictions

Do not create a hero headline, full About section, complete project case
study, visual component plan, or code instructions.

Do not create new professional claims to make the brief sound stronger.

If the profile is sparse, recommend a shorter portfolio rather than
inventing sections or adding filler.
