Forma.

A visual system for a more approachable way to organize the everyday.

Concept / Brand and digitalYear / 2026Role / Direction, design, prototype
Forma / The new shape of simpleforma.
01 / Context02 / Idea03 / Result

A clearer place to begin.

Forma is a sample concept for an everyday planning tool. The design question was simple: how can organization feel supportive instead of demanding?

The result starts with calm structure, generous space, and a visual language that helps people find the next useful step.

One idea, many expressions.

A flexible circle becomes the core of the identity. It can frame a message, guide the eye, or become a quiet moment of motion. The system stays recognizable without repeating the same layout everywhere.

Made for real life.

The concept brings identity and interface into one coherent experience. The project shown here is fictional sample content for previewing this standalone stylesheet.
