# OryxenAI — Deferred Suggestions

This is an intentionally unlinked, non-authoritative holding file for ideas
outside the accepted MVP. It is not an architecture decision, roadmap,
implementation plan, prompt source, acceptance contract, or input for an
implementation AI. No item below is approved merely because it is recorded
here. Work may begin only after the project owner explicitly promotes an item
into the authoritative plan and, where needed, `DECISIONS.md`.

- **Broad or golden inspiration corpus:** Maintain a licensed, privacy-safe
  collection of diverse visual references and evaluation cases for advanced,
  non-generic composition without copying a reference site.
- **Build Theater / unverified candidate preview:** Show generation activity or
  an isolated work-in-progress rendering without allowing it to become the
  trusted current preview or weakening promotion gates.
- **Live development container:** Add a persistent isolated development server
  with hot reload for internal iteration after the immutable build pipeline is
  proven reliable.
- **Publishing adapters:** Promote a verified preview artifact to explicitly
  configured hosting providers through separate, provider-neutral adapters.
- **Authenticated sharing:** Add expiring, revocable, access-controlled preview
  sharing for collaborators outside the owning session.
- **Expanded cross-browser coverage:** Extend the required browser matrix after
  the primary isolated browser and viewport journeys are stable.
- **Cost and prompt caching:** Reuse safe prompt prefixes, model results, or
  evaluation work by content hash after correctness, quality, observability,
  and invalidation semantics are established.
