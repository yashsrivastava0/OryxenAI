# Deployment Issues Archive

This directory stores archived, resolved deployment issue logs from [`docs/deployment/deployment-issues.md`](../deployment-issues.md).

## Archiving Policy
- [`deployment-issues.md`](../deployment-issues.md) has a strict line budget (< 400 lines) to prevent blowing up AI agent context windows (Codex, Claude Code, Antigravity, Cursor).
- When resolved issues in the active document exceed 15 items or total file length exceeds 350 lines, older resolved records are moved here into timestamped archive files (e.g., `deployment-issues-archive-2026.md`).
- Active blockers and recent resolved references always remain in the primary [`deployment-issues.md`](../deployment-issues.md).
