## Legacy namespaced plural owners change stable admissions — HIGH · confirmed

`_resource_contracts` expands every item with multiple owners into `@route` slot and need IDs without considering source format (`src/oryxenai/agents/code_generator/core/brief_ingestion.py:1321-1324`). The pre-change namespaced behavior produced one unsuffixed first-route slot. `_role_sections` preserves historical matching (`brief_ingestion.py:1461-1482`), but not this surrounding topology.

A compiler probe produced `shared-image@home` and `shared-image@work` for the same two-route payload under unversioned namespaced, legacy `build-preparation-brief-v1` namespaced, and new namespaced dispatch. The contract/admitted identity remains input-derived (`brief_ingestion.py:313-325,509-523`), while projection hashes change independently (`brief_ingestion.py:504-506`). The exact guard at `src/oryxenai/agents/code_generator/core/generation_orchestrator.py:819-831` prevents stale-plan execution by returning `INPUT_PROJECTION_DRIFT`, but cannot resume the historical run. Preserve legacy topology or version/migrate the compiled identity; the single-route continuity test at `tests/unit/agents/code_generator/test_development_input.py:710-762` misses this case.

## Legacy declarations inherit current producer requirements — MEDIUM · confirmed

`_validate_wire_shape` computes `declared_shape` before source dispatch, then requires resource `need_id` and `status` and component `need_id` for every declaration (`brief_ingestion.py:725-740`). The pre-change namespaced validator did not require those fields. A probe confirmed that a namespaced resource missing `need_id` and `status` compiles unversioned but fails the historical v1 declaration with `BRIEF_STRUCTURE_UNRECOGNIZED` and `missing_fields=need_id,status`.

Keep strict types and forbidden extras, but select historically accurate required fields after dispatch. `test_declared_v1_requires_all_current_producer_fields` covers a current declared raw shape (`tests/unit/agents/code_generator/test_development_input.py:599-618`), while the namespaced continuity test uses `_resource_entry`, which always supplies both fields (`test_development_input.py:271-290`); neither exercises the legacy shape.

## Route suffixes can collide with authored projection IDs — MEDIUM · confirmed

Only base role IDs are checked in `seen_roles` (`brief_ingestion.py:1284-1292`). Generated IDs are appended without final uniqueness validation (`brief_ingestion.py:1321-1324,1348-1373`), and the wire contract does not reserve `@`.

A probe with plural role `shared`/need `need` and single-owner role `shared@home`/need `need@home` compiled successfully with duplicate `shared@home` slots and duplicate `need@home` needs. Plan validation eventually rejects duplicate plan slots (`src/oryxenai/agents/code_generator/core/development_planner.py:305-315`), but admission has already accepted and hashed the ambiguous projection. Reserve or encode the suffix and validate all final IDs across resource and component entries before returning projections.

## Global raw-ID uniqueness rejects current producer output — HIGH · confirmed

`_canonicalize_raw_content_index` keys its map only by local section ID and rejects a second occurrence anywhere (`brief_ingestion.py:910-951`). The regression at `tests/unit/agents/code_generator/test_development_input.py:782-799` expects two routes containing `hero` to fail, narrowing rather than adapting the route-owned producer contract.

Build Preparation emits each section under a route while globally de-duplicating raw navigation tokens (`src/oryxenai/agents/build_preparation/brief_assembly.py:72-77,137-153`). Content Architect enforces section uniqueness only within each route pack (`src/oryxenai/agents/content_architect/validators.py:322-335`; `content_architect/state.py:313-324`). A producer probe built a declared raw-v1 pair containing `home/hero` and `work/hero`; `compile_briefs` rejected that exact output with `BRIEF_SECTION_DUPLICATE` before any model call.

Canonicalize by `(route_id, local_section_id)`, parse section-content headings within their route, and expand the closed navigation mapping deterministically. If global uniqueness is intentional instead, enforce it before Build Preparation emits a brief and document the breaking restriction. Until then, `test_raw_v1_requires_bijective_route_local_section_mapping` is false-positive evidence for compatibility.

## Offline regression blind spots — confirmed

Offline validation passed: 51 focused input tests, the targeted projection-drift integration test, and 8 Build Preparation integrator tests. Existing cases cover recursive duplicate keys, non-coercing types, nested dependency rejection, current raw plural expansion, producer declarations, dispatch provenance, and model-free resume rejection.

**Confirmed not tested:** plural ownership through legacy namespaced dispatch; previously accepted declared namespaced records missing current fields; synthesized/authored ID collisions; and a multi-route pair from `build_content_brief` with repeated local IDs. These four regressions should accompany the fixes.
